# Figma Make design brief

Create a beautifully crafted, fully responsive interactive product prototype for **Counting Cards**, a daily card-memory and blackjack training app. This is the product itself, not a marketing landing page. Interface copy should be in Czech, using correct diacritics and concise, natural language. PAO, Hi-Lo and blackjack terminology can remain familiar.

You are the visual design lead: choose the palette, typography, composition, surfaces and visual direction yourself. Aim for a premium, memorable training club with the precision of a good fitness app and the quiet atmosphere of an elegant card room. Do not feel bound to green-and-gold casino clichés. Avoid neon, kitsch, generic AI dashboard styling, emoji icons, or a school-form appearance. Make bold but coherent choices. Cards must remain instantly recognizable traditional playing cards: ivory/white faces, red hearts/diamonds, black clubs/spades, correct ranks, proper pip arrangements, mirrored corners, attractive illustrated J/Q/K. Prioritize excellent card assets. Use tasteful textures, icon libraries and subtle animation where appropriate.

Design this to be realistically implementable in React/TypeScript with reusable components and CSS tokens. We will separately implement and rigorously verify the training engines; your main job is exceptional visual and interaction design. Still make representative flows interactive so we can review them. Include both empty/new-user and populated demonstration states; label any demo statistics clearly, never imply that a new user has already trained.

PRODUCT STRUCTURE
- Home training hub: a compelling but compact daily-training hero, continue/start action, relevant progress, and clear groups for Memory and Blackjack. Explain what each mode trains. Make getting into a session effortless. A focused desktop sidebar and excellent mobile navigation are possible, but choose the best structure.
- Memory: PAO library/learning/test; Sequence Memory; Shuffle Memory; Missing Cards; Visual Memory.
- Blackjack: Hi-Lo Counting; Basic Strategy; Practice Table (simulation).
- Progress: actual-looking records, accuracy, activity/history, progression towards a full 52-card deck.
- Settings/data: preferences, keyboard guide, export/import PAO and progress. Data stays on this device, so show clear backup affordances.

DESIGN THE REAL TRAINING STATES, NOT JUST A DASHBOARD
1. PAO library: all 52 cards, suit filters, search, configured/partial/complete/missing indicators. Clicking a card opens a beautiful focused editor with Person / Action / Object (Osoba / Akce / Předmět), Save, Clear, Previous, Next. One nonempty association is enough; all three are optional individually. Include counts such as 37/52 configured, with partial versus complete distinction. Do not force three fields. Make keyboard navigation quick.
2. PAO Learn and Test: learning reveals the saved associations; testing shows one card and inputs only for configured fields. Immediate per-field feedback, correct answer, progress, next card. Also represent reverse association-to-card testing and a useful empty state when no cards are configured.
3. Sequence Memory: setup for card count 1–52, speed presets 0.2/0.5/1/2 seconds and custom speed, round count, recall type, optional progression (start, increment, successful rounds needed). Default full recall. A distraction-free memorization stage displays one large readable card at a time, with progress and pause/exit. Recall hides every answer and presents numbered slots plus a picker containing the full 52-card deck, suit filters, touch-friendly tap-to-place, and drag/reorder interaction. Allow undo/removal. Never require typing card names. Also show random-position, reverse-order and missing-position variants. Results show score, expected and submitted order, position-level errors, memorization/answer times, speed, best and immediate Next Round / Try Again.
4. Shuffle Memory: after memorizing, a readable operation timeline explains a deterministic cut, move top N to bottom, deal into 2/3/4 piles, gather in specified order, or riffle. Show pile/card movement tastefully and clearly. Setup includes deck size and operation complexity; recall can target first N, one position or full deck. Transform the underlying order consistently. Animation is explanatory, never dead time.
5. Missing Cards: set suit, rank range, number missing, display duration and rounds. Show the remaining cards then hide them; user chooses absent cards from a picker; show clear comparison feedback.
6. Visual Memory: set card count/grid and display duration. Show cards together, hide them, then reconstruct the grid, name the card at a position, or find a named card's position. Use a stable spatial layout throughout.
7. Hi-Lo Counting: choose deck count, starting count, cards per checkpoint, speed, rounds/difficulty. Show classic Hi-Lo legend: 2–6 +1, 7–9 0, 10/J/Q/K/A −1. Deal readable cards rapidly then ask the running count with a large signed numeric input and immediate feedback. Show true count separately with decks remaining if useful; do not confuse it with running count.
8. Blackjack Strategy: display the dealer upcard and player hand on a refined table. Large Hit / Stand / Double / Split actions, optional Surrender. Provide rules panel: decks, dealer hits/stands soft 17, double restrictions, double after split, surrender, resplit. Result explains the rule-based correct action. Visually distinguish hard/soft totals and pairs.
9. Practice Table: represent dealing to player/dealer, concealed hole card, player actions, hand result and an occasional running-count checkpoint. Training only, no wagering/payment UI needed. Focus on the real card-table feeling.
10. Progress: per-mode meaningful stats, clean charts and session history. Personal milestones from 3 to 52 cards with customizable progression. Make zero-data states honest and motivating.

INTERACTION AND QUALITY BAR
- Mobile-first, excellent at 390px and desktop 1440px. No horizontal page overflow. Large cards during timed sessions; 44px+ touch targets; pickers and 52-card recall remain usable on a phone.
- Strong typography and spacing hierarchy, purposeful use of negative space, accessible contrast and visible focus. No tiny washed-out labels. Use real icons, not emoji.
- Build subtle tactile card hover/lift, short transitions, a satisfying result reveal and clear reorder feedback. Respect prefers-reduced-motion. Animations never delay training; card exposure interval is independent of animation duration.
- Space = start/next, Enter = submit, R = restart, Esc = exit, without intercepting typing. Show a compact shortcut hint only where useful.
- Provide focused setup, memorization, recall, correct/incorrect result and empty-state screens. Navigation and core demo flows should work. Make the UI feel like a polished product someone would enjoy for ten minutes daily.
- Keep all files/assets organized and exportable. Please build the complete visual system and representative screens now, with particular care for home, the 52-card PAO editor, sequence recall on mobile, and the blackjack table.
